## 1. 一句话现状

导出的髋部垂直幅度只有视频的 86%，根因是 ExMR 单目把「屈膝下蹲→顶髋伸直」的腿部屈伸律动估僵、
把剩余弯曲做成「朝镜头弯」。已实现 6.1（根平移垂直增益自动校准）与 6.2（2D 几何驱动腿屈伸重拟合），
配合后骨盆 v 幅度回到视频的 **97%**、顶胯幅度回到 **98%**、全腿屈伸律动回到 **86%**，
膝盖 2D 误差不劣化。

---

## 2. 根因结论（简述，详见根因文档）

- 4–5s 段左腿：视频大腿投影长 ptp=26.6px，ExMR 仅 10.5px（40%），屈伸律动被腰斩。
- ExMR 大腿 3D 长恒等于物理值 0.3941m（SMPL 刚性），但膝盖 3D 向量朝镜头（`Kex-H` 的 z 分量为负）。
- 8 个关节级证据：髋被压缩（0.76–0.90）、膝/踝被放大（1.23）、肩正常（1.04）——是关节级分配错误，非均匀偏小。
- 裁剪放大输入无效（86%→81%），已排除。
- COCO knee 与 SMPL knee 定义差：大腿角距离系统性偏大 7.8%（常数偏置，非随动作耦合）。
- 两个障碍决定了实现路径：① 解析反投影不可行（271/301 帧无解）→ 必须做带约束优化；
  ② 朝镜头弯导致膝盖 u 方向相对髋反号，绕 X 轴无法修 → 只对齐 v。

## 3. 可行性验证（实施前，纯 numpy 内联脚本）

在真实数据上用 `runtime_exmr/python.exe` 跑一次性脚本，确认方案可行后才落地：

| 验证项 | 结论 |
| --- | --- |
| 绕 X 轴屈伸 + 深度优化 | 大腿长律动 10.5 → 19.8px（视频校正后 24.7 的 80%），腿长偏离 1–2%，可行 |
| 只对齐 v，不对齐 u | u 方向 ExMR +9.8px vs 视频 −4.5px，需 ~1.3m 深度变化才能修，不可行，放弃 |

| 深度 δ 左右独立 | 会把双脚拉开一前一后（见 §6 问题 2），后续移除 |

关键数值：`KNEE_CORR = 1/1.078`（图像空间缩短视频膝盖沿「髋→膝」方向 7.8%）。

### 4.2 `refit_legs`（6.2）

流程五步：

1. 用 `record["smpl_params_incam"]` 经 `_rest_joints` + `_forward_aa` 得到相机系 22 关节位置 `positions` 与世界旋转 `joint_world`。
2. 逐腿逐帧优化屈伸角 θ（1 变量）：
   - 参数化 `K = H + Rx(θ)·(Kex − H)`，`Rx` 绕世界 X 轴（矢状面），踝保持 ExMR 位置不动。
   - 残差：`(vK − vH − target_v)/σ_v` + 小腿长软约束 + `θ/σ_flex` + 膝盖向前约束。
   - `target_v = (视频膝v − 视频髋v) · KNEE_CORR`，`vH` 为 ExMR 髋投影 v（相对 2D 隔离髋误差）。
   - `least_squares(method="trf")`，`θ ∈ [−1.2, arctan(−Z/Y)]`：上界保证膝盖不越过髋正下方。
3. 时间平滑：θ 序列 `_gaussian(σ=REFIT_SMOOTH_FRAMES=2 帧)`，消除 2D 关键点噪声引起的腿抖。
4. 反解 UpLeg/Leg：复用 `align` 把大腿方向对齐到 `newK−H`、小腿方向对齐到 `A−newK`，
   踝世界旋转保持不变（脚不动）。局部旋转与坐标系无关，可直接写回 global body_pose。
5. 返回 `(n, 63)` 的 global body_pose。`drive=0`（参数 `hip_bob_gain`）返回 ExMR 原样。

关键常量（`hip_motion.py` 顶部）：

```python
BEND_LIMITS = (0.0, 1.0)      # 2D 驱动强度，exmr_options 引用
KNEE_CORR = 1.0 / 1.078       # COCO knee 定义差校正
REFIT_V_SIGMA = 8.0           # v 对齐（px）
REFIT_LEN_SIGMA = 0.06        # 小腿长软约束（相对 ±6%）
REFIT_FLEX_SIGMA = 1.0        # 屈伸角正则（rad）
REFIT_FORWARD_SIGMA = 0.05    # 膝盖往后惩罚
REFIT_SMOOTH_FRAMES = 2.0     # θ 时间平滑（帧）
```

### 4.3 `_bob_gain`（6.1）与根跟随平滑

- `_bob_gain(camera_root, keypoints, K, fps)` = 视频骨盆 v ptp / **平滑后**相机系骨盆投影 v ptp，
  clip 到 `GAIN_LIMITS=(0.2, 3.0)`。本片算出 **1.146**（文档预期 1.16）。
- 关键：bob 必须用平滑后的投影算，否则垂直平滑造成的幅度衰减补不回来（实测 ptp 会掉到 0.1217）。
- `match_video` 顺序：`follow_camera_root` → `scale_excursion(followed, sway, bob)` → `refit_legs`。
  6.1 改 transl、6.2 改 body_pose，解耦、顺序叠加。
- `_camera_path` 三轴平滑：水平 X **2 帧**、垂直 Y **2 帧**、深度 Z **0.5s**（`DEPTH_SECONDS`）。

### 4.4 GUI 使用

勾选 **Match Video Hip Amplitude** → Sway=1.0、Leg Refit=1.0 → 点 **Reconstruct 3D**（会重跑 ExMR GPU 推理，
因为 `hip_motion.py` 哈希进签名）→ **Apply Correction**。关闭态由 POLICY_ONLY 别名保证老工程不重算。

## 6. 用户反馈问题与修复（逐轮）

这是本实施中最有价值的部分——以下 6 个问题都是**用户真实重跑后逐帧观察**发现的，修复后才收敛。

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 勾选后腿抖（帧间最大 43°） | 逐帧独立优化，2D 噪声直接传导成 θ 帧间跳变 | θ 时间平滑 σ=2 帧，max 降到 12° |
| 2 | 103 帧双脚一前一后 | 深度偏移 δ 左右腿独立优化（δL−δR 达 0.13m），踝 Z 差从 6cm 拉到 15cm | **移除 δ**，只优化 θ，踝保持 ExMR 位置；踝 Z 差回到 6cm，律动反而略好 |
| 3 | 勾选后上下跳（帧间最大 7cm） | `follow_camera_root` 垂直原样带入 incam 逐帧噪声，bob 再放大 | 垂直 2 帧平滑 + bob 用平滑后投影算；max 降到 2.3cm，幅度保持 100% |
| 4 | 帧 21–22 左右晃 | 水平 X 只用 1 帧平滑 | 水平平滑加到 2 帧，膝盖 X 抖动回到接近不勾选水平 |
| 5 | 帧 90 左腿往后屈膝 | θ 只对齐 v、无方向约束，优化把膝盖从髋前 6cm 翻到髋后 3cm | θ 加上界 `arctan(−Z/Y)`（膝盖不越过髋正下方），用 `bounds` 硬约束；回到髋正下方 |
| 6 | 129 帧顶胯「整个人往上」 | 非 bug：6.1 正确恢复了视频顶胯（1.9cm→12.5cm，视频 12.8cm）；不勾选时这段几乎不动 | 无需修复，向用户解释；「整体抬升 vs 屈膝」比例问题是 6.2 残余（见 §7） |

### 踩坑要点（务必记住）

1. **δ 不能用**：深度偏移即使左右共享也会带来不必要自由度，θ 绕 X 轴屈伸本身已包含足够的深度调整。
   左右独立 δ 是「双脚一前一后」的直接原因。
2. **bob 的口径**：必须用平滑后的相机系投影算增益；用未平滑投影会导致幅度补不回来。
3. **θ 必须有上界**：否则 v 对齐会把膝盖推向髋后方（生理上不合理），90 帧就是实例。
4. **只对齐 v 是取舍**：u 方向 ExMR 本身反号且绕 X 轴修不了，强行对齐会把 θ 带偏；当前接受 u 不修。
5. **验证解释器**：快速度量用 3.10 不行（correction 的 cp310 `.pyd`），完整链路必须用 `runtime/python.exe`（3.10）；
   但 `refit_legs` 的 scipy 在 3.12/3.10 都可用。

## 7. 当前状态与残留

已解决：幅度（97%）、顶胯（98%）、腿屈伸律动（86%）、腿抖、双脚一前一后、左右晃、上下跳、膝盖 2D 误差不劣化。

残留（非本次范围，后续按需处理）：

- **屈膝恢复 86%**：顶胯里仍有部分靠根平移（整个人抬）而非屈膝伸直。要进一步提升需重调 6.2 的
  目标口径或权重，属独立优化，风险较高，本轮未动。
- **u 方向未修**：膝盖左右位置偏移（朝镜头弯的副作用），绕 X 轴不可修，需侧机位素材评估后再定方案。
- **踝 Y 残余抖动 5.5mm**：`follow_camera_root` 用 incam 逐帧根的固有噪声（不勾选 2mm），
  再强平滑会衰减顶胯/下蹲的快速律动，当前 σ=2 是平衡点。
- **`women_dance` 踝滑 2.5cm**：略超 2cm 验收线，但脚底不穿地（0mm），属 balance 模式残余。
